# 💪 Calculateur de Masse Maigre

Une application web simple et responsive permettant de calculer la Masse Maigre (Lean Body Mass - LBM) à l’aide de plusieurs formules scientifiques.

---

## 🚀 Fonctionnalités

- Calcul instantané de la masse maigre
- Interface utilisateur simple et intuitive
- Design responsive (mobile et desktop)
- Utilisation de formules scientifiques fiables
- Application rapide et légère

---


## 🧮 Formules utilisées

### 📌 Formule de Boer

#### Homme
```text
LBM = (0.407 × poids) + (0.267 × taille) − 19.2
```

#### Femme
```text
LBM = (0.252 × poids) + (0.473 × taille) − 48.3
```

---

### 📌 Formule de James

#### Homme
```text
LBM = 1.1 × poids − 128 × (poids / taille)²
```

#### Femme
```text
LBM = 1.07 × poids − 148 × (poids / taille)²
```

## 📖 Utilisation

1. Entrer :
   - le poids
   - la taille
   - le genre

2. Cliquer sur le bouton **Calculer**

3. Obtenir instantanément le résultat de la masse maigre
